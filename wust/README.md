# Course Copilot 武科大版

本目录归档 **Course Copilot 武科大版**（武汉科技大学）。仓库根目录是 **Course Copilot 武大版**（武汉大学，v1.0.0）的源码。

两条产品线共用同一套评分引擎与卡片视图，但**读取端、评价源、推荐分组完全不同**。发布物也分开放：武大版在 `_release-assets/whu/`，武科大版在本目录 `plugin/`。

## 两个版本怎么区分

| | 武大版（仓库根目录） | 武科大版（本目录） |
|---|---|---|
| 学校 | 武汉大学 | 武汉科技大学 |
| 选课页 | `jwgl.whu.edu.cn/xsxk/...` | `bkjx.wust.edu.cn/jsxsd/xsxk/xsxk_index` |
| 读取方式 | 渐进式观察课程卡片，原生「有余量」筛选 | 读 `dataView` 14 列表格，逐页读、每页保存后翻页 |
| 评价源 | `whucourses.cn` 接口 | **本地评价 JSON 导入**（网站接口尚未接入） |
| 推荐输出 | 单一榜单 | 按线上 / 线下 / 混合 / 待确认**分组**分别排序 |
| 当前版本 | 扩展 v1.0.0 | 插件 v0.5.1 · 识别模块 v0.2.2 · 网站 v1.8.0 |
| 发布物 | `_release-assets/whu/` | `plugin/`、`reader/` |

共用部分：`vendor/engine.mjs`（评分、匹配、权重、置信度）与 `vendor/presentation.mjs`（卡片与偏好视图）是从武大版构建产物原样搬入的，算法内容未改；武科大版只替换了读取端与评价 provider，并在其上叠加了授课方式分组。

## 安全边界

不选课、不退课、不提交、不碰登录/密码/cookie。只读页面 + 请求评价源；推荐只代表「基于现有数据哪个更贴合偏好」，不保证选上，也不代表课程质量排名。
