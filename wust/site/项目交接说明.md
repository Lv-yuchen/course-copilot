# 武科大课程评价网站：Windows 继续开发交接说明

更新时间：2026-10-10。沿用现有项目与设计，暂不与课程助手插件联动。无需 npm install。

## Windows 启动
安装 Node.js 24 或以上，解压整个包，在 wust-review-site 目录执行 `node server.mjs`，浏览器打开 http://127.0.0.1:4317/ 。也可双击“启动网站.cmd”。
管理后台 /admin，新电脑首次启动生成管理密码，保存在 .local/admin-secret.txt。迁移包不含旧管理密码。

## 本次已完成与用户决定
- 保留米白、深绿整体设计，右侧独立投稿卡片使用浅薄荷绿（#e7f2ed）。
- 列表按课程归组，点击“查看老师”展开教师卡片，点击“查看评价”进入该教师独立详情。分页按课程，同一课程教师不拆页。
- 详情包含结构化概览、成绩统计、学期筛选、完整评价和预填课程教师的投稿入口。完整评价直接呈现，不折叠；不展示来源和评价编号。
- 新投稿推荐程度、难度、作业量采用五档必选；考勤/作业/考核各自合并为方式选项+详细说明。课程内容与总体评价放在表单末尾。文字不设字数限制，必填字段非空；请求仍有64KB技术上限。
- 成绩状态已出分/未出分；已出分必填精确0–100百分制成绩，未出分留空。个人成绩字段不随评价返回；聚合至少10份，教师/学期筛选后同样适用。统计含均分、中位数、总体标准差及分布。
- 当前第一版投稿校验通过后直接发布，不人工审核、不调用AI，并获得全站长期阅读资格。历史待审核记录保留。
- 游客看基础信息与结构化概览；完整评价、成绩均分/分布由服务端限制。新生独立通道填写当年入学年份、学院、身份、关注课程，权限当年9月1日（北京时间）至次年9月1日。无姓名、学号、校园密码；不是学生身份核验。
- 匿名阅读凭证通过HttpOnly Cookie管理，数据库保存哈希。资格持久，Cookie一年；换设备/清除Cookie暂无恢复。无法保证同一个真实人只能领取一次。迁移包清空reader_access凭证表，Windows重新领取权限。
- 用户已明确“大英=大学英语”，合并为大学英语；“有机”改为有机化学。course-names.mjs集中别名映射，搜索/投稿自动统一；实验课与不同等级课程不做模糊吞并。保留旧课程ID跳转映射。
