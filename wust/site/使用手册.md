# 课里有话 · 武科大网站测试使用手册

版本：网站 v1.8.0，测试包日期：2026-10-11。

## 一、这个测试包是什么
这是可在自己电脑上运行的网站测试包，包含完整网站源码、已整理的课程与历史评价数据库、课程指南原文件，以及配套选课插件下载包。无需 npm install。测试包已清除原开发者的账号会话、恢复码、通知和管理密码。课程资料用于测试与参考，更新可能不及时，以学校通知和教务系统为准。

## 二、启动网站
1. 先安装 Node.js 24 或以上版本。
2. 将整个 ZIP 解压到固定文件夹。不要直接在压缩包里运行文件，也不要只复制其中一个文件。
3. Windows 双击“启动网站.cmd”。Mac 在终端进入解压文件夹，执行 `PORT=4318 node server.mjs`；也可用附带的 Mac 启动脚本。
4. 在浏览器打开 http://127.0.0.1:4318/ 。保持启动窗口打开，关闭窗口会停止网站。
5. 本包在本机运行，每个测试者的数据互相独立，不会回传给开发者。需要共同访问一份在线网站时，另行部署。

## 三、普通用户功能流程
首页 → 查找课程或教师 → 展开老师 → 查看课程详情 → 分享修读经历 → 保存账号恢复码 → 查看完整评价与成绩统计。

### 查找课程
支持按课程、按教师、课程＋教师搜索；可按课程属性、线上或线下筛选。相同课程按教师展示独立评价，同名课程的线上与线下记录分开。同一教师不同修读学期可按已有评价筛选。

### 课程详情与数据说明
课程页展示已有的基本信息与简介。考勤与课堂管理、作业情况、期末考核和课程体验分栏呈现。缺失信息不会凭空补充。游客能查看基础信息；完整评价及详细成绩统计需要阅读资格。精确个人成绩不随单条公开评价展示。历史评论中的成绩描述可用于标明来源的文字参考统计，与精确自报成绩区分。

### 发布评价
填写实际修读过的课程和教师。课程可选栏包含全部已有课程，也允许填写新课程。课程属性、授课方式、修读学期、成绩状态、推荐程度、难度、作业量、考勤、作业、期末考核及总体体验均需填写。三项程度使用小方块单选，选中后墨绿高亮。
已出分需要填写0—100分精确总评；未出分可先提交，之后会有补成绩提醒。请使用真实、客观的经历和文明表达。
提交后直接发布，管理员不定期复核。完整投稿获得长期阅读资格。请保存首次自动生成的账号恢复码。

### 新生阅读资格
未修读过课程的新生可在登录／解锁页面填写当年入学年份、学院、身份与关注课程，领取新生阅读资格。期限为入学当年9月1日至次年9月1日。此通道为自行声明，当前没有学校身份核验。

### 我的评价与小铃铛
“我的评价”可查看本人投稿，修改或撤回可操作的评价，补充未出分成绩。修改后重新进入后台待复核列表；已隐藏或撤回的评价按现有状态限制操作。
小铃铛显示投稿成功、修改、补成绩、本人撤回、管理员撤回及原因等通知；支持单条或全部标为已读。临近到期的新生资格会有提醒。

## 四、恢复码账号怎么用
恢复码就是当前账号的找回凭证，无需另设用户名密码。首次获得资格后保存它；持有码的人能够恢复该账号，请勿公开分享。
已登录：顶部“账号 · 长期阅读／新生权限” → 账号管理 → 再次保存恢复码 → 复制或下载。重复保存返回同一个码，不会作废原码。
换设备或退出后：打开登录／解锁页面 → 输入恢复码 → 恢复账号。恢复后继承原阅读资格、投稿管理和消息记录，包括消息已读状态。
退出当前账号只撤销当前设备会话，不删除投稿，不使恢复码失效。退出后可用原码再次登录。
新测试包从空账号状态开始，没有旧版恢复码兼容问题。若迁移旧项目，只有哈希的旧码需从此前保存文件找回，输入一次后才能重复保存。
如果恢复码丢失且所有设备均已退出，当前版本没有姓名、学号或邮箱找回通道。

## 五、后台管理员测试
1. 首次启动会随机生成本测试副本的管理员密码。
2. 打开“.local/admin-secret.txt”复制密码，在 http://127.0.0.1:4318/admin 登录。可用“查看管理密码.cmd”读取。
3. 待复核列表用于检查已直接发布的投稿；确认保留，或填写理由后撤回展示。
4. 撤回理由会发送到投稿者小铃铛。隐藏后公开课程页与统计应不再包含该评价；后台与本人记录保留。
5. 可检查举报反馈和历史处理记录。恢复展示后，应重新出现在公开页面。
管理密码与普通用户恢复码是两种不同凭证。请勿把生成后的个人测试数据库或密码公开发布。

## 六、课程指南与配套插件
课程指南分“选课指南”和“线上课程学习指南”，提供原始PPT或Word文件下载。
主页配套插件入口提供 Course Copilot 武科大版 v0.5.1 介绍、安装说明与 ZIP 下载。插件需要手动加载到 Edge。当前插件与本站评价尚未自动同步，推荐需要导入本地评价 JSON；单独下载插件不会自动获得本站评价。此次主要测试网站。

## 七、建议按顺序测试
- 游客搜索一个课程和一个教师，切换线上／线下，翻页并进入详情。
- 提交一条明确注明“测试投稿”的评价；先选择未出分，检查必填提示与小方块。
- 保存恢复码，检查完整阅读资格、小铃铛和“我的评价”。
- 修改该评价，再补充成绩，检查展示与通知。
- 管理员隐藏评价并填写理由；检查用户收到原因，公开页不再展示。
- 管理员恢复展示，用户检查记录。
- 退出当前账号，再用同一恢复码登录，核对投稿与消息是否继承。
- 再次保存恢复码，核对与首次保存的一致。
- 最后自行撤回测试投稿，检查公开页与统计变化。
- 下载一份指南和插件 ZIP，确认可打开。

测试建议使用虚构的“测试课程／测试老师”，不要捏造真实教师评价。本地副本只用于测试。

## 八、怎样反馈测试结果
复制“测试反馈模板.md”填写：操作步骤、期望结果、实际结果、浏览器版本、截图。恢复码、管理密码无需提供。
测试数据不会自动传回。若需要定位数据问题，请先联系开发者约定提供哪些文件，勿直接发送整个带账号凭证的“.local”目录。

## 九、常见问题
- 提示找不到 node：安装 Node.js 24+ 后重新打开启动脚本。
- 端口被占用：关闭之前的网站启动窗口，或使用其他端口启动，例如 `PORT=4319`（Windows 设置环境变量后运行），并打开对应地址。
- 页面没有更新：刷新页面，确认访问的是启动窗口显示的地址。
- Mac 脚本无法双击：使用终端启动即可。
- 恢复码无效：核对是否完整、是否属于当前这个网站副本，以及新生资格是否已到期。不同测试者的本地数据库相互独立，不能跨副本恢复。
- 备份进度：停止网站后复制整个文件夹，尤其保留“.local/reviews.sqlite”。不要只保存源码，否则会丢失测试投稿和账号。

## 十、开发与验证信息
原生 Node.js HTTP + SQLite，无外部前端依赖。入口 server.mjs，页面在 public，课程资料在 data，数据库在 .local。运行 `node --test test.mjs test-semantic-audit.mjs` 可检查功能。发布本包前，28项检查通过；数据库完整性检查通过。此结果不代表每一种浏览器与操作均已实际人工验证。
