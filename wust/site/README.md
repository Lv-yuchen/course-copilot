# 课里有话 · 武科大课程评价网站 v1.1

本地 Node.js + SQLite 网站，保留原设计、历史数据与历史投稿管理。暂不接入插件；采用贡献解锁与新生通道，不核验学生身份。

## 本版功能

- 搜索按“课程＋教师”分别显示，每个组合有独立 `/course?id=…&teacher=…` 页面。教师未知的评价单独保留，不猜测合并别名。
- 详情包含概览、成绩统计、学期筛选、完整评价、投稿入口。历史缺失字段保持未知，不自动生成评分。
- 新投稿必须选择推荐程度、课程难度、作业量（均为5档），以及考勤、作业、期末考核形式；详细说明和课程体验必填，没有文字字数限制。
- 已出分必须填写0–100精确百分制成绩；未出分不填成绩。本版尚未支持等级制、通过制成绩，也未提供后续补分入口。
- 普通详情接口不返回单条成绩。达到10份有效成绩才展示平均分、中位数、总体标准差、分布；教师与学期筛选后同样适用。
- 原文可能包含学生自行写入的成绩或身份线索，历史原文尚未逐条脱敏。公开发布前需整理；聚合门槛尚未实现防差分推断或小分组抑制。
- 不做学生身份认证；采用贡献解锁与新生通道。管理员仍可查看历史待审核投稿原始成绩。

## Mac 启动

安装 Node.js 24 或以上，在本目录执行 `node server.mjs`，打开 http://127.0.0.1:4317/ 。无需 npm install。

管理后台 `/admin`，管理密码保存在 `.local/admin-secret.txt`。数据库 `.local/reviews.sqlite`，包含迁移数据。运行中的数据库请使用 SQLite 备份接口；文件复制备份应在停服后进行。

## 验证

`node --test test.mjs`：覆盖导入、检索、分页、投稿校验、待审核隔离、审核HTTP流程、教师与学期隔离、成绩门槛和详情成绩字段剥离。

新接口：`GET /api/offerings`（course、teacher、category、mode、page）；`GET /api/offerings/:id?teacher=规范化教师标识&term=学期`。

## 阅读权限（第一版）

游客可浏览基础信息和结构化概览；完整文字与成绩统计由服务端限制。完整投稿成功后直接发布并获得长期阅读资格，无需人工或AI审核。新生填写当年入学年份、学院、身份、关注课程获得当年9月1日至次年9月1日阅读资格。

匿名凭证使用 HttpOnly Cookie，数据库只存凭证哈希；资格持久保存，Cookie有效期一年。清除Cookie或换设备暂无恢复途径；无法保证真实的人只领取一次。新生资料不参与评价统计。历史待审核投稿仍留在管理后台。

- 新增数据库表 review_owners、reports、review_actions；原数据未删除，迁移前快照在 .local/before-content-tools.sqlite。
- 10组自动测试全部通过，新增覆盖投稿者隔离、举报权限、处理原因、隐藏/恢复与成绩门槛联动、撤回及禁止管理员恢复撤回评价。实际浏览器已检查详情反馈表单、“我的评价”及内容管理后台。

新投稿先发布、后复核：已发布但未复核的学生投稿同时出现在后台待审核列表，管理员确认保留后移出，隐藏后退出统计。投稿修改后重新进入复核列表。历史 Excel 导入不进入新投稿审核队列。新增 review_checks 表保存复核状态。
