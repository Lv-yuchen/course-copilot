Course Copilot

武汉大学自主选课浏览器扩展

读取你自己已登录的选课页面上已有的课程信息，结合公开学生评价，按可调偏好给出确定性、可解释的推荐。

它做什么

一次点击「加载可选课程信息并生成推荐」，即完成三件事，全部有界且只读：

  • 启用页面自带的「有余量」筛选，让候选池只包含当前可选课程
  • 点页面底部的「点此查看更多」，把剩余结果加载完（上限 20 次点击）
  • 仅对教师信息不完整的课程面板展开详情，补全任课老师

随后重新读取整页并交给推荐引擎。准备过程中可随时取消；取消后已加载的信息保留，并可再次开始。

确定性推荐

同样的课程数据 + 同样的偏好，必然得到同样的顺序与分数。每条推荐带推荐分、置信度与逐维度证据。

页面事实

余量与本轮已选直接读取页面公布的数字。竞争提示仅在「本轮已选 > 本轮余量」时出现，且明确不代表选中概率。

学生评价原文

来自公开的 whucourses.cn，每门课最多 3 段原文摘录，按需展开。不改写、不做 AI 摘要。

可调偏好

成绩友好 / 工作量轻松 / 考勤宽松 / 学生评价 四个 0–10 滑杆，默认 50% / 30% / 15% / 5%。

安装

本版本以「已解压扩展」形式提供，尚未上架任何扩展商店。

  1. 从 Release 页面 下载 course-copilot-v1.0.0.zip 并解压到你想长期保留的位置
  2. 打开 edge://extensions/（Chrome 为 chrome://extensions/）
  3. 打开开发人员模式
  4. 点加载解压缩的扩展，选择解压出来的文件夹（里面应直接看到 manifest.json）
构建完成后不需要任何本地后端或开发服务器。 本项目不存在任何 Course Copilot 服务器。

安全边界

以下均由代码强制，并有自动化门禁断言，不只是文案：

行为状态
自动登录 / 处理帐号密码 / 读取或传输 cookie不做
选课 / 退课 / 提交或确认不做
页面字段读取范围仅课程列表与已授权的座位字段
公共评价请求仅发往 https://whucourses.cn，且带 credentials: omit
权限仅 sidePanel
宿主权限仅 https://whucourses.cn/*

从源码构建

pnpm install
pnpm extension:build

产物在 apps/extension/dist。

已知限制

  • 只支持一个页面：仅 jwgl.whu.edu.cn/xsxk/zzxkyzb_cxZzxkYzbIndex.html，其它教务页面不注入
  • 公开评价覆盖不均：冷门课可能证据不足，会列在「评价证据不足」区而不是被硬塞进推荐
  • 自报成绩不是官方平均分：样本来自学生自愿评价
  • 竞争提示不是录取概率
  • 推荐是决策辅助，最终以教务系统为准

本项目是个人开发的第三方工具，与武汉大学没有任何隶属、合作或背书关系。 课程与评价数据均来自公开来源，可能滞后或有误；任何选课决定及其后果由使用者自行承担。
