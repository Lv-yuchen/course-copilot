# Course Copilot v1.0.0

首个正式版本。武汉大学自主选课的**浏览器扩展**（Edge / Chrome，Manifest V3）——读取你自己已登录的选课页面上已有的课程信息，结合公开学生评价，按可调偏好给出**确定性**排序。

**它不是选课机器人**：不选课、不退课、不提交，也不接触你的帐号密码。

---

## 安装

本版本以「已解压扩展」形式提供，尚未上架任何扩展商店。

1. 下载下面的 `course-copilot-v1.0.0.zip` 并**解压**到你希望长期保留的位置
2. 打开 `edge://extensions/`（Chrome 为 `chrome://extensions/`）
3. 打开**开发人员模式**
4. 点**加载解压缩的扩展**，选择解压出来的文件夹（里面应直接看到 `manifest.json`）

构建完成后不需要任何本地后端或开发服务器。

> 也可以从源码构建：`pnpm install && pnpm extension:build`，产物在 `apps/extension/dist`。

## 这个版本包含

### 课程数据准备流水线
一次点击「加载可选课程信息并生成推荐」即完成三件事，全部**有界**且只读：

- 启用页面**自带的**「有余量」筛选，使候选池只包含当前可选课程
- 点页面底部的「点此查看更多」，把剩余结果加载完（上限 20 次点击）
- 仅对**教师信息不完整**的课程面板展开详情，补全任课老师

随后重新读取整页并交给推荐引擎。准备过程中可随时**取消**；取消后已加载的信息保留，并可**再次开始**。

### 确定性推荐
同样的课程数据 + 同样的偏好，必然得到同样的顺序与分数。每条推荐带：

- **推荐分** —— 这门课有多贴合你的偏好
- **置信度** —— 这个推荐背后的数据有多可靠（与「课好不好」无关）
- **逐维度证据** —— 成绩友好 / 工作量轻松 / 考勤宽松 / 学生评价 各自有多少条评价真的提到了

### 页面事实
- **余量**、**本轮已选**：直接读取页面公布的数字
- **保守的竞争提示**：仅当「本轮已选 > 本轮余量」时出现，并明确说明**不代表选中概率**

### 学生评价原文
来自公开的 `whucourses.cn`，每门课最多 **3 段原文摘录**，按需展开，**不做改写、不做 AI 摘要**。

来源归属保守：来自当前教师的评价标注教师名；只能代表课程整体的明确标为「**课程整体参考**」；无法确定归属时写「**教师信息未明确**」。

### 成绩数据
紧凑一行显示，例如 `学生自报平均成绩：90.6（28份，当前教师）`。

**成绩数据来自学生评价中的自报成绩，并非武汉大学官方课程平均成绩。**

无可用样本时显示「暂无数据」，**不会显示为 0**；缺失数据在计分时重新分配权重。

### 个性化偏好
四个 **0..10 整数**滑杆，默认 `10 / 6 / 3 / 1`（即归一化 **50% / 30% / 15% / 5%**）：

| 控件 | 默认 |
|---|---|
| 成绩友好 | 10/10 · 50% |
| 工作量轻松 | 6/10 · 30% |
| 考勤宽松 | 3/10 · 15% |
| 学生评价 | 1/10 · 5% |

- 右侧百分比是**相对重要程度**，不需要凑满 100
- 拖动一个滑杆**不会**移动其它滑杆
- **全为 0 无效**，会拒绝并提示
- 改完后点「更新推荐」**只重新排序**，不会再动你的页面

### 侧栏
推荐快照、「有评价，但未进入推荐」默认折叠区、每张卡片默认折叠的学生评价模块、单一共享的成绩免责声明。

## 安全边界

以下均由**代码强制**，并有自动化门禁断言，不只是文案：

- 不自动登录 · 不处理帐号密码 · 不读取或传输 cookie
- 不选课 · 不退课 · 不提交或确认
- 页面字段读取仅限课程列表与已授权的座位字段
- 公共评价请求只发往 `https://whucourses.cn`，且带 `credentials: omit`
- **不存在任何 Course Copilot 后端服务器**
- 权限仅 `sidePanel`；宿主权限仅 `https://whucourses.cn/*`

---

## 已知限制

- **只支持一个页面**：仅 `jwgl.whu.edu.cn/xsxk/zzxkyzb_cxZzxkYzbIndex.html`；其它教务页面不注入
- **公开评价覆盖不均**：冷门课可能证据不足，会列在「评价证据不足」区而不是被硬塞进推荐
- **自报成绩不是官方平均分**：样本来自学生自愿评价
- **竞争提示不是录取概率**
- 推荐是决策辅助，**最终以教务系统为准**
