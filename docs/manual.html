开始之前：你需要知道的三件事

  1. 它不会替你选课。它只读课程信息、给建议。选课、退课、提交全部要你自己在教务系统里点。
  2. 它不接触你的密码。你要自己正常登录教务系统；插件不参与登录、也读不到你的帐号。
  3. 它需要挂在Edge（或 Chrome）浏览器上运行，装好后会在浏览器右侧开一个侧栏。

最快上手（如果只有 30 秒）

步骤 你要做的 你会看到

一、这是什么

Course Copilot 是一个浏览器扩展，给武汉大学自主选课用。它读你页面上已经有的课程信息，结合公开的学生评价，按你自己设的偏好给出一份有排序的推荐，帮你在候选课之间做比较。

它不是抢课/选课机器人，也不是武汉大学官方产品。它是个人的决策辅助工具，最终结果一律以教务系统为准。

它只在一个页面上工作

目前只支持这一个网址（通识/自主选课页面）：

https://jwgl.whu.edu.cn/xsxk/zzxkyzb_cxZzxkYzbIndex.html

其它教务页面（成绩、课表、其它选课入口等）不在支持范围，侧栏会显示「当前未检测到支持的 WHU 自主选课页面」。这不是故障。

二、安装（用我给你的压缩包）

2.1 解压

  1. 找到我发给你的 course-copilot-v1.0.0.zip。
  2. 右键 → 全部解压缩（或「解压到 course-copilot-v1.0.0\」）。

    建议解压到一个固定的、不会被你随手删掉的位置，比如 D:\CourseCopilot\。因为插件是「从这里加载」的：这个文件夹一旦被删或移动，插件就会失效。

    解压后应该直接看到 manifest.json 这个文件，像这样：

    course-copilot-v1.0.0\
├─ manifest.json          ← 必须在这一层
├─ background\
├─ content\
└─ sidepanel\

    如果解压出来多套了一层同名文件夹（manifest.json 在第二层），那就选里面那一层。

2.2 装进 Edge（推荐）

  1. 打开 Edge。
  2. 地址栏输入 edge://extensions/ 并回车。
  3. 左下角打开「开发人员模式」开关。
  4. 上方会出现「加载解压缩的扩展」按钮，点它。
  5. 在弹出的选择框里，选中你刚才解压出来的那个文件夹（选中文件夹本身，不用进去选文件），然后确定。

    成功的话，扩展列表里会出现一张名为 Course Copilot 的卡片，版本显示 1.0.0。

    顺便把它固定到工具栏：点地址栏右边的拼图图标 → 找到 Course Copilot → 点旁边的图钉/眼睛图标。这样后面点它开侧栏更方便。

2.3 用 Chrome 装（可选）

步骤完全一样，只是地址变成 chrome://extensions/，开关叫「开发者模式」。我在 Edge 上完整测过；Chrome 理论上一致，如果你用 Chrome 遇到问题也请告诉我。

2.4 关于「开发者模式」的提示

  • 这是正常的：会一直显示一条「请停用以开发者模式运行的扩展程序」之类的提醒，点关闭即可，不影响使用。
  • 原因是：因为它是未上架商店的测试版。我准备正式发布时会处理这个。
  • 如果失效了：如果哪天插件突然消失，多半是浏览器重启或更新清掉了它，按 2.2 重装一次即可。

三、怎么用

3.1 完整流程

  1. 自己登录武大教务系统（正常输帐号密码，插件不参与）。
  2. 打开自主选课页面：https://jwgl.whu.edu.cn/xsxk/zzxkyzb_cxZzxkYzbIndex.html
  3. 点工具栏上的 Course Copilot 图标，右侧打开侧栏。确认它显示「已识别 WHU 自主选课页面」。

    点侧栏里那个大按钮：「加载可选课程信息并生成推荐」。点这一下就等于你同意了接下来的全部操作。

  4. 等侧栏跑完。你会依次看到下面的字，别急着关：
    侧栏显示 它正在做什么
    正在开始… 刚收到你的指令
    正在筛选可选课程… 启用页面自带的「有余量」筛选，只保留现在还能选的课
    正在加载可选课程… 自动点页面底部的「点此查看更多」，把剩下的结果加载完
    正在补全教师信息… 对教师信息不完整的课程，展开详情把老师名字读出来
    正在重新读取课程信息… 把整理好的整页再读一遍
    可选课程信息已准备完成 准备结束，马上开始算推荐
  5. 随后自动出现「推荐快照」，里面就是推荐结果。
  6. 可选：你可以展开某门课的「查看学生评价」看真实评价原文，也可以调偏好后点「更新推荐」重排。

    整个准备过程大约几十秒到一两分钟，取决于课程数量。过程中随时可以点「取消」；取消后已经加载的信息会保留，你可以再点一次开始。

3.2 侧栏在报告什么

侧栏顶部会显示两个信息：

  • 页面识别：「已识别 WHU 自主选课页面」或「当前未检测到支持的 WHU 自主选课页面」
  • 面板数量：「检测到课程面板：N」—— 页面上找到了多少个课程条目

    底部还有一行「版本」，显示 1.0.0。如果这里不是 1.0.0，说明加载的不是我这次的包，请告诉我。

四、怎么看懂一张推荐卡片

每张卡片上的字段，含义如下：

卡片上的字段 含义 怎么理解
任课老师 页面公布的授课老师 补全教师信息之后才会完整
课程代码 教务系统的课程编号 方便你去教务系统核对
学分 学分值 页面没给就显示「学分：暂无数据」，不会瞎猜
余量 现在还剩多少名额 显示「未知」就是页面没公布
本轮已选 本轮已经选上这门课的人数 显示「未知」就是页面没公布
可选状态 有余量 / 已满 / 状态未知 直接来自页面，不参与打分
推荐排名 #1、#2… 按你的偏好算出的顺序
推荐分 这门课的综合得分 分越高越贴合你设的偏好
置信度 这个推荐有多可信 看的是数据够不够，不是课好不好
证据 各维度的证据充分程度 例如「证据充分（28/37）」＝ 37 条评价里 28 条提到了这一项
评价样本 这门课有多少条公开评价 样本少的时候，结论要打折看
查看学生评价（N） N 段学生原文摘录 点一下展开，默认收起

4.1 三个数字要分清

「推荐分」「置信度」「证据」是三个不同的问题，不要混着看：

  • 推荐分回答：这门课适合你吗？
  • 置信度回答：关于这门课的数据够不够多、够不够可靠？
  • 证据回答：具体到「给分」「工作量」「考勤」这些方面，有多少条评价真的提到了？

    所以「推荐分高但置信度低」是完全可能的：方向对，但样本少，别太当真。

4.2 结果分成三块

区域 含义
推荐课程 排名靠前、建议优先看的课
有评价，但未进入推荐 有公开评价，但综合下来没排进前面。默认折叠，点标题才展开
评价证据不足 公开评价太少，没法给出可靠判断。会列出来，但不会被硬塞进推荐

关于成绩数字：卡片上的「学生自报平均成绩」来自学生自己填的成绩，不是武汉大学官方课程平均分。括号里是样本数和这个数字代表谁，例如「90.6（28份，当前教师）」。没有样本时显示「暂无数据」，不会显示成 0。

关于「竞争较高」提示：只有当「本轮已选」大于「余量」时才会出现，意思是「选的人比名额多」。它只是人数和名额的关系，不代表你选上的概率。任一数字缺失时不会显示这个提示。

五、个性化偏好（按你的想法调整排序）

侧栏里有「个性化偏好」，默认是收起的，点一下展开。里面有四个滑杆：

面板上每个滑杆右边会显示两个数，例如 10/10 50%：左边是你拖到的档位，右边是它折算出来的占比。四个滑杆的默认值是：

滑杆 含义 默认显示 折算占比
成绩友好 越容易拿好成绩，越推荐 10/10 50%
工作量轻松 作业和考核越少，越推荐 6/10 30%
考勤宽松 点名越少，越推荐 3/10 15%
学生评价 评价正文越正面，越推荐 1/10 5%

怎么用：

  • 每个滑杆是 0 到 10 的整数。数字越大 ＝ 你越在意这一项。
  • 滑杆右边会实时显示折算出来的百分比，那是「相对重要程度」。

    你不需要把百分比凑成 100。拖一个滑杆不会自动动别的滑杆。

  • 如果四项全是 0，会提示「至少有一项重要程度需要大于 0。」—— 这是故意的，因为全 0 等于没偏好。
  • 点「恢复默认」回到 10 / 6 / 3 / 1（即 50% / 30% / 15% / 5%）。

    改完偏好后点「更新推荐」，只会重新排序：不会再启用筛选、不会再点「点此查看更多」、不会再展开教师详情。所以这一步很快，也不会重复动你的页面。

六、学生评价是真的吗？

  • 来源：来自公开的 whucourses.cn（课程评价网站），是学生自己写的。

    每门课最多展示 3 段原文摘录，长度也有上限。不做改写、不做 AI 总结—— 你看到的就是原话（可能是错别字、可能有情绪，都是原文）。

  • 归属：来自当前老师的评价会标明老师名字；只能代表整门课的评价会写「课程整体参考」；

    万一无法确定归属，会写「教师信息未明确」—— 宁可说不确定，也不硬说成是当前老师的评价。

七、安全声明（这条最重要）

下面这些不是口头承诺，是代码里写死的限制，有自动化检查在守着：

它绝对不会做的事 说明
不会自动登录 登录完全由你自己完成
不会读你的密码 代码里没有任何处理帐号密码的地方
不会读取或上传 cookie 不碰浏览器的登录凭证
不会选课 没有任何报名动作
不会退课 没有任何退课动作
不会提交 / 确认 不存在任何表单提交
没有服务器 不存在 Course Copilot 的后端，你的数据不会被传到任何服务器
只访问两个网站 选课页面 jwgl.whu.edu.cn，和公开评价站 whucourses.cn

它会对你的页面做的操作只有四种：启用页面自带的「有余量」筛选、点一次页面的「查询」、点「点此查看更多」、展开教师信息不完整的课程。

这些都在你点「加载可选课程信息并生成推荐」那一下被一次性授权。

八、已知限制（先说清楚，免得你以为坏了）

  • ① 只支持一个页面。其它教务功能页不工作，侧栏会说不支持。
  • ② 热门课评价多，冷门课可能没几条评价。这类课会出现在「评价证据不足」里，而不是被硬推荐。
  • ③ 成绩是学生自报的，样本有限，不能当官方平均分用。
  • ④ 「竞争较高」只是人数和名额的比较，不是录取概率。
  • ⑤ 推荐只代表「基于现有数据哪个更贴合你的偏好」，不保证你选得上、也不代表课程质量排名。

九、遇到问题怎么办

现象 先这样试
侧栏说「当前未检测到支持的 WHU 自主选课页面」 确认你打开的是那个自主选课网址，并且已经登录；刷新页面再试
点按钮后没反应 确认页面课程列表已经出来（不是空白/加载中）；刷新页面再试一次
侧栏显示「已停止数据准备，已经加载的信息会保留。」 这是取消后的正常提示。再点一次「加载可选课程信息并生成推荐」即可
显示「当前页面无法使用 WHU 的"有余量"筛选，因此未开始准备数据。」 页面的筛选控件没找到。刷新页面重试；若一直如此请截图告诉我
显示「未能启用"有余量"筛选，因此未开始准备数据。」 筛选点了但页面没生效。刷新重试；持续出现请截图
某门课显示「该课程公开评价暂时不可用」 评价站暂时没响应或不收录这门课。不影响其它课
插件整个消失了 浏览器重启/更新把它清了，按第二章重装一次
版本显示的不是 1.0.0 说明加载的不是这次的包，请重新解压安装

重要：如果插件有任何异常，不要去点教务系统里的「选课」「退课」「提交」来试探 —— 插件本身不碰这些，你也不需要为它承担任何选课风险。
