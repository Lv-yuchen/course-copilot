# Course Copilot

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

武汉大学自主选课的个人决策助手，以浏览器扩展形式运行（Edge / Chrome，Manifest V3）。

它**不是选课机器人**。它读取你已经登录的选课页面上**已经存在**的课程信息，结合公开的学生评价语料，按你自己设定的偏好给出**确定性**排序，帮你在候选课之间做比较。选课、退课、提交全部由你自己在教务系统里完成。

> 第一次使用请看 **[使用手册](docs/manual.md)**。

> **两个版本**：仓库根目录是 **武大版**（武汉大学，扩展 v1.0.0）；**武科大版**（武汉科技大学，插件 v0.5.1）单独放在 [`wust/`](wust/README.md)。两者共用同一套评分引擎，但读取端、评价源与推荐分组不同；发布物分别在 `_release-assets/whu/` 和 `wust/plugin/`，不要混用。

---

## 它做什么

在支持的 WHU 自主选课页面上，点一次「加载可选课程信息并生成推荐」，扩展会：

1. 启用页面**自带的**「有余量」筛选，使候选池只包含当前可选课程；
2. 点页面底部的「点此查看更多」，把剩余结果**有界地**加载完；
3. 仅对**教师信息不完整**的课程面板展开详情，补全任课老师；
4. 重新读取整页，并把课程数据交给推荐引擎；
5. 在侧栏给出带分数、置信度与逐维度证据的推荐。

全程只读 + 上述有限点击。**不会选课、退课或提交。**

## 功能

| 功能 | 说明 |
|---|---|
| 自动启用 WHU「有余量」筛选 | 使用页面**原生**控件，不伪造状态；若页面无法应用该筛选，则停止而不是分析未筛选的课程池 |
| 有界加载「点此查看更多」 | 上限 20 次点击，达到上限会明确告知，且已获取数据保留 |
| 有界补全教师信息 | 只展开信息不完整的课程面板；已完整的面板不会被重复点击 |
| 确定性课程排序 | 同样的课程数据 + 同样的偏好，必然得到同样的顺序与分数 |
| 推荐分 / 置信度 / 逐维度证据 | 三个不同的量，分别回答「多合适」「数据多可信」「每个维度证据多充分」 |
| 余量 | 直接读取页面公布的剩余名额 |
| 本轮已选 | 直接读取页面公布的本轮已选人数 |
| 保守的竞争提示 | 仅当**本轮已选 > 本轮余量**时出现；不给出任何录取概率 |
| 紧凑的学生自报平均成绩 | 一行显示，并标明该数字的归属（当前教师 / 当前教学班 / 课程整体参考） |
| 真实学生评价原文 | 每条课程最多 3 段**原文摘录**，按需展开，不做改写 |
| 可调推荐偏好 | 四个 0..10 整数滑杆；改动后「更新推荐」即时重排，**不重跑页面准备** |
| 「有评价，但未进入推荐」折叠区 | 有可用评价但排名未进前列的课程，默认折叠 |
| 取消与重新开始 | 准备过程中可随时取消；取消后可再次开始，已加载的信息保留 |

扩展的 content script 只在这一个 URL 模式下注入。**其它 WHU 页面（包括其它教务功能）不在支持范围内**，侧栏会明确显示「已识别 WHU 自主选课页面」或未识别。

## 安装（手动 / 开发者方式）

发布包以「已解压扩展」形式提供，尚未上架任何扩展商店。

1. 安装依赖（仓库根目录）：

   ```bash
   pnpm install
   ```

2. 构建扩展：

   ```bash
   pnpm extension:build
   ```

   等价命令：

   ```bash
   node scripts/build-extension.mjs
   ```

3. 打开浏览器的扩展管理页：

   - Edge：`edge://extensions/`
   - Chrome：`chrome://extensions/`

4. 打开右上角的**开发人员模式**。

5. 点**加载解压缩的扩展**（Load unpacked）。

6. 选择构建产物目录：

   ```
   apps/extension/dist
   ```

**构建完成后不需要任何本地后端或开发服务器。** 扩展产物是 6 个静态文件，直接由浏览器加载。

## 使用方法

1. 在浏览器中**自己登录**武汉大学教务系统（扩展不参与登录，不接触帐号密码）。
2. 打开上面那个受支持的自主选课页面。
3. 打开 Course Copilot 侧栏。
4. 点「**加载可选课程信息并生成推荐**」。这是整个准备流程的**唯一授权**：一次点击 = 同意上述筛选、加载与教师补全。
5. 等待侧栏依次报告：`正在筛选可选课程…` → `正在加载可选课程…` → `正在补全教师信息…` → `正在重新读取课程信息…` → `可选课程信息已准备完成`。
6. 随后自动生成推荐，出现「推荐快照」。
7. 可以展开任意课程的「查看学生评价」看原文，或在「个性化偏好」里调整权重后点「更新推荐」重排。

准备过程中随时可以点「取消」。取消后已加载的数据保留，侧栏回到可再次开始的状态。

## 推荐偏好

四个控件，全部是 **0..10 的整数**：

| 控件 | 含义 | 默认 |
|---|---|---|
| 成绩友好 | 越容易拿到好成绩越推荐 | 10 |
| 工作量轻松 | 作业与考核越少越推荐 | 6 |
| 考勤宽松 | 点名越少越推荐 | 3 |
| 学生评价 | 评价正文越正面越推荐 | 1 |

默认值 `10 / 6 / 3 / 1` 归一化后即 **50% / 30% / 15% / 5%**。

- 面板在每个滑杆右侧显示**实时归一化百分比**，它是**相对重要程度**，不是「必须凑满 100」的配额；你不需要、也不应该为了凑 100 而去调别的滑杆。
- 拖动某一个滑杆**不会**自动移动其它滑杆。
- **全为 0 无效**：会拒绝并提示「至少有一项重要程度需要大于 0。」
- 「恢复默认」写回 `10 / 6 / 3 / 1`。
- 改偏好后点「更新推荐」只**重新排序**：不会再启用筛选、不会点「点此查看更多」、不会展开教师详情。

## 学生评价证据

- 评价语料来自公开的 `whucourses.cn`。
- Course Copilot 展示的是**学生原文摘录**，不做 AI 改写、不做润色、不做摘要生成。
- 每条课程**最多 3 段**摘录，每段有长度上限。
- **来源归属保守**：来自当前教师评价的摘录会标注教师名；只能代表课程整体的评价会明确标为「**课程整体参考**」；无法确定归属时写「**教师信息未明确**」，而不会硬说成是当前老师的评价。
- 评价原文以纯文本渲染，**不会被当作 HTML 解释**。
- 摘录只是证据展示；**是否推荐由确定性引擎按上面的维度算出**，与摘录条数无关。

## 成绩数据

课程卡片上的成绩行读作：

```
学生自报平均成绩：90.6（28份，当前教师）
```

**成绩数据来自学生评价中的自报成绩，并非武汉大学官方课程平均成绩。**

- 括号里的 `28份` 是样本数，`当前教师 / 当前教学班 / 课程整体参考` 是该数字的归属。
- 没有可用样本时显示「**暂无数据**」——**不会显示为 0**。
- 缺失的数据在计分时被**重新分配权重**，不会被当成 0 分。

## 竞争提示

当且仅当满足：

```
本轮已选 > 本轮余量
```

课程卡片会显示：

> 竞争较高：本轮已选人数已超过本轮余量，最终结果仍以选课系统为准。
>
> 此提示仅反映当前人数与余量关系，不代表选中概率。

这是**人数与余量的原始事实比较**，不是概率、不是风险分、也不是录取预测。任一数值缺失（显示「未知」）时不会显示该提示，也**不会**给出反向的「竞争较低」标签。

## 安全与隐私

以下全部由**代码强制**，不只是文案：

| 项 | 状态 |
|---|---|
| 自行手动登录 WHU | 是 —— 扩展无任何登录/凭据处理代码 |
| 自动登录 | **无** |
| 读取或传输 cookie | **无**（代码中不存在 `document.cookie` / `chrome.cookies`） |
| 选课 / 退课 / 提交 / 确认 | **无**（不存在任何报名、退课、表单提交动作） |
| 帐号密码处理 | **无** |
| 把 WHU cookie/token 发给任何后端 | **无** —— 不存在 Course Copilot 后端服务器 |
| 页面字段读取范围 | **仅** 课程列表与已授权的座位字段（`blzyl`、`blyxrs`）；禁用字段与祖先遍历在门禁中被断言为 0 |
| 公共评价请求 | 只发往 `https://whucourses.cn`，且带 `credentials: omit` |
| 权限 | 仅 `sidePanel`；宿主权限仅 `https://whucourses.cn/*` |

扩展对课程页面的操作**只有**：启用页面自带的「有余量」筛选（各一次展开与选择）、点一次「查询」、有界地点「点此查看更多」、以及为补全教师信息展开课程详情。这些都在你点击「加载可选课程信息并生成推荐」时被一次性授权。

## 架构

```
WHU 自主选课页面
      │  （content script：只读 + 上述有限点击）
      ▼
规范化课程数据
      │
      ├──► 公开评价 provider（whucourses.cn，带 TTL 缓存）
      │
      ▼
确定性推荐引擎（纯函数：同样的输入必然同样的输出）
      │
      ▼
侧栏呈现（推荐快照 / 卡片 / 学生评价摘录）
```

生产运行时是：

```
apps/extension/    扩展本体（content script、service worker、侧栏）
packages/          核心类型、评价 provider、推荐引擎
```

| 目录 | 内容 |
|---|---|
| `apps/extension/` | 扩展本体：content script、service worker、侧栏、manifest |
| `packages/core/` | 核心类型、课程解析、评价维度抽取、打分、匹配、排名 |
| `packages/provider/` | 公开评价数据源、缓存、限流、评价摘录 |
| `packages/recommendation/` | 确定性推荐引擎 |
| `scripts/` | 构建与门禁脚本 |
| `test/` | 测试套件 |
| `docs/` | [使用手册](docs/manual.md) |

## 已知限制

- **只支持一个页面**：目前只针对 WHU 自主选课页面；其它教务页面不注入、不支持。
- **公开评价覆盖不均**：热门课程评价多，冷门课程可能没有足够证据，会出现在「评价证据不足」区而不是被硬塞进推荐。
- **自报成绩不是官方平均分**：样本来自学生自愿评价，样本量和代表性都有限。
- **竞争提示不是录取概率**：它只是「本轮已选 > 本轮余量」这一事实的表达。
- **推荐是决策辅助**：最终选课结果、名额与规则都以武汉大学教务系统为准。
